# Reels & Shorts Blocker Extension

A lightweight Chrome Extension that blocks **YouTube Shorts** and **Instagram Reels** by automatically redirecting them to their respective home pages.

## 🚀 Features

- Automatically redirects:
  - `https://www.youtube.com/shorts/...` → `https://www.youtube.com/`
  - `https://www.instagram.com/reels/...` → `https://www.instagram.com/`
- Toggle blocking ON/OFF from the popup
- No unnecessary permissions
- Lightweight and fast

## 📦 How to Install

1. Clone or download this repository.
2. Go to `chrome://extensions/` in your Chrome browser.
3. Enable **Developer mode** (top-right toggle).
4. Click **Load unpacked** and select the project folder.
